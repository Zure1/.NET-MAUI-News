## Framework and runtime

### 1. .NET MAUI 10.0.120 released

- **What changed:** On October 21, Microsoft published the latest stable .NET MAUI 10 servicing release. Its release notes list fixes for grouped `CollectionView` behavior, iOS item layout and selection, Windows `CarouselView` scrolling, and retained objects in visual diagnostics and UI components. The notes also include branch-specific and candidate work, so individual fixes should be validated in the actual installed build rather than assumed from PR titles alone.
- **Recommended action:** Evaluate 10.0.120 in a staging branch. Run UI regression tests for `CollectionView` (grouping, empty states, rotation, selection and large grid lists), navigation, Windows input, and memory retention before production rollout.
- **Source link:** [Official 10.0.120 release notes](https://github.com/dotnet/maui/releases/tag/10.0.120)

### 2. .NET MAUI 11 RC2 and the new platform baseline

- **What changed:** .NET 11 RC2 was announced October 13; the MAUI 11.0.100-rc.2 workload was published October 15. Workload set `11.0.100-rc.2.26513.2` contains MAUI `11.0.0-rc.2.26505.5`, .NET for iOS/Mac Catalyst 27.0, and .NET for Android 37.2.0-rc.2.84. The release specifies Xcode 27.0, JDK 21, Android API 37, and Windows App SDK 2.3.1. .NET 11 migration also involves the CoreCLR default, new handler paths, and removal of the optional `Microsoft.Maui.Controls.Compatibility` package.
- **Recommended action:** Test .NET 11 in a separate branch with a pinned workload set. Compare Release builds for startup, memory, size, trimming/NativeAOT compatibility, Shell navigation, `CollectionView`, custom handlers, and native libraries. Check any explicit Compatibility package reference. Use a Visual Studio version that supports the .NET 11 prerelease toolchain.
- **Source link:** [MAUI 11 RC2 release](https://github.com/dotnet/maui/releases/tag/11.0.100-rc.2) · [.NET 11 MAUI migration details](https://learn.microsoft.com/dotnet/maui/whats-new/dotnet-11) · [.NET 11 RC2 announcement](https://devblogs.microsoft.com/dotnet/dotnet-11-rc-2/)

### 3. October out-of-band .NET security update

- **What changed:** On October 25, Microsoft issued .NET 10.0.14 and .NET 11 RC3 to address a Brotli decompression buffer-overflow vulnerability (CVE-2026-111497), along with other security corrections. The Brotli issue can affect apps using Brotli APIs or configured HTTP decompression. A Linux tarball ownership issue primarily concerns build and installation environments. The update also completes fixes not fully addressed in the October 13 servicing release.
- **Recommended action:** Patch .NET SDKs and runtimes on developer machines, CI agents and build images; rebuild and retest affected MAUI apps. Check whether the app or its networking stack processes Brotli-compressed content. If evaluating .NET 11, use RC3 for the runtime security fixes while checking the MAUI workload compatibility separately.
- **Source link:** [Microsoft's October 25 security advisory](https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/)

## Apple platforms and build tooling

### 4. Xcode 27 requires scene lifecycle migration for older app projects

- **What changed:** Microsoft's October 19 guidance confirms that an iOS or Mac Catalyst app built with Xcode 27 can exit immediately after its splash screen unless it uses UIKit's scene lifecycle. Existing projects are not automatically migrated by updating packages. A typical migration adds a `MauiUISceneDelegate` subclass and `UIApplicationSceneManifest` to the appropriate platform files. Custom authentication redirects, cold-start deep links, notifications, App Actions and window lifecycle callbacks may also need changes. The newer Apple SDKs raise minimum deployment targets to iOS 15 and Mac Catalyst 17.
- **Recommended action:** Migrate all shipping plist configurations before building with Xcode 27. For .NET 10, use MAUI 10.0.110 or later for scene-aware App Actions and `WebAuthenticator` forwarding. Test cold launch, background/foreground, login redirects, links, notification taps and shortcuts on iOS 27; repeat for Mac Catalyst where applicable.
- **Source link:** [Microsoft's Xcode 27 migration guide](https://devblogs.microsoft.com/dotnet/migrate-dotnet-maui-apps-uikit-scene-lifecycle/)

### 5. Stable .NET 10 Apple workloads add Xcode 27.1 support

- **What changed:** On October 19, the .NET for iOS team released iOS workload `27.1.10018` for Xcode 27.1. The published installation combination is .NET SDK `10.0.402` and workload set `10.0.402.1`, with MAUI `10.0.110+` recommended. The workload requires Xcode 27.1 and macOS 26.6 or later. Apple released Xcode 27.2 on October 29, but that is not the version specified by this workload.
- **Recommended action:** Pin .NET SDK, workload set and selected Xcode together in local development and macOS CI. Do not automatically switch a MAUI build agent to Xcode 27.2 without a matching .NET for iOS release. Check `dotnet workload --info` and `xcodebuild -version` when diagnosing signing, archive, simulator or Pair-to-Mac failures.
- **Source link:** [Official Xcode 27.1 workload release](https://github.com/dotnet/macios/releases/tag/dotnet-10.0.1xx-xcode27.1-10018) · [Apple Xcode 27.2 release information](https://support.apple.com/en-us/149589)

## Libraries, publishing and support

### 6. CommunityToolkit.Maui compatibility remains a .NET 11 migration checkpoint

- **What changed:** No new stable CommunityToolkit.Maui release was identified for October. The August 21 release `15.0.1` remains the published compatibility baseline for upcoming .NET 11 apps: it removes remaining dependencies on MAUI internal APIs and addresses a Windows App SDK dependency mismatch. The maintainers explicitly warn that toolkit 14.2.2 and earlier will not work with .NET 11.
- **Recommended action:** Inventory toolkit packages and third-party controls before the .NET 11 upgrade. Test `CommunityToolkit.Maui` 15.0.1 or later, especially Popup, FileSaver, FolderPicker, Toast, Snackbar, Expander and TouchBehavior, on each supported platform. Do not assume that the same Windows App SDK dependency works across .NET 10 and .NET 11.
- **Source link:** [CommunityToolkit.Maui 15.0.1 release notes](https://github.com/CommunityToolkit/Maui/releases/tag/15.0.1)

### 7. Google Play's 2026 Android target-API extension reaches its deadline

- **What changed:** Google Play has required Android 16 / API 36 for new mobile apps and updates since August 31, 2026. Developers of affected apps could request an extension until November 1, 2026. Existing-app discoverability has a separate minimum target of API 35. This is a publishing deadline, not a new October SDK release.
- **Recommended action:** Verify the `targetSdkVersion` of Android release artifacts, not just the build SDK. Ensure upcoming Play submissions target API 36 or higher and retest edge-to-edge layout, permissions, notifications, back navigation, and 16 KB page-size compatibility where relevant.
- **Source link:** [Google Play target API requirements](https://support.google.com/googleplay/android-developer/answer/11926878)

### 8. .NET MAUI 10 support window confirmed

- **What changed:** Microsoft's support-policy page, updated October 22, lists MAUI 10.0.120 as the latest supported patch and May 11, 2027 as the end-of-support date for .NET MAUI 10. MAUI 9 is already out of support.
- **Recommended action:** Keep production apps on supported MAUI 10 servicing releases while testing .NET 11 migration. Add the May 2027 MAUI 10 support cutoff to upgrade planning.
- **Source link:** [Official .NET MAUI support policy](https://dotnet.microsoft.com/en-us/platform/support/policy/maui)

# .NET MAUI News — August 2026

**Date range covered:** 01. 08 → 31. 08  
**Signal level:** High

## Key updates

This month was mostly about the .NET 10 servicing line, .NET 11 preview readiness, CoreCLR migration, and Android/iOS/Windows reliability fixes.

| Area | Update |
|---|---|
| Stable servicing | .NET MAUI 10.0.100 shipped on 20 August. |
| Preview track | .NET MAUI 11 Preview 7 shipped with quality, performance, accessibility, and tooling improvements. |
| Runtime | CoreCLR is now the only runtime for .NET MAUI mobile apps in .NET 11 Preview 6+. |
| Reliability | August work included Android MediaPicker, SafeArea, shadow scrolling, and Windows Map crash fixes. |
| Memory/build health | A `BindingDiagnostics.BindingFailed` retention issue was fixed with weak-event handling. |

## Top highlights

### .NET MAUI 10.0.100 shipped

**What changed**

The .NET MAUI 10 servicing line advanced to 10.0.100 on 20 August 2026. The release sits alongside the August servicing work that also included Android, iOS, Windows, build, and dependency updates.

**Recommended action**

Move production apps to the latest 10.0 servicing build after running platform smoke tests, especially around MediaPicker, navigation, SafeArea, and packaging.

**Source link**

- [Daily repository status — 21 August 2026](https://github.com/dotnet/maui/issues/37701)
- [Daily repository status — 23 August 2026](https://github.com/dotnet/maui/issues/37754)

### .NET MAUI 11 Preview 7 shipped

**What changed**

.NET 11 Preview 7 shipped on 11 August 2026. The preview includes MAUI changes across XAML, Shell, CollectionView, BlazorWebView, tooling, and accessibility. The MAUI repository also moved toward RC1 alignment during the month.

**Recommended action**

Use Preview 7 only in a dedicated preview lane. Validate startup, trimming/AOT, navigation, CollectionView behavior, and device-specific UI before broader adoption.

**Source link**

- [.NET 11 Preview 7 is now available](https://devblogs.microsoft.com/dotnet/dotnet-11-preview-7/)
- [Daily repository status — 13 August 2026](https://github.com/dotnet/maui/issues/37374)

### CoreCLR becomes the only mobile runtime in .NET 11 previews

**What changed**

In .NET 11 Preview 6, CoreCLR became the only runtime for .NET MAUI Android, iOS, and Mac Catalyst apps. Microsoft describes the mobile runtime work as functionally complete and is asking developers to test real applications before .NET 11 GA.

**Recommended action**

Run representative apps on .NET 11 previews with full release-style settings, including trimming, AOT, native linking, signing, startup measurement, and crash reporting. Keep a rollback path to .NET 10.

**Source link**

- [CoreCLR Progress and the Mono Timeline for .NET MAUI](https://devblogs.microsoft.com/dotnet/coreclr-progress-and-mono-timeline-dotnet-maui/)

### Android reliability fixes landed

**What changed**

August repository work included fixes for a severe Android shadow-container scrolling regression, stale permission requests after off-main-thread failures, SafeArea handling during IME animations, and MediaPicker behavior that could overwrite picked source files.

**Recommended action**

Add or refresh Android regression tests for keyboard open/close flows, SafeArea layout, permission denial/retry, MediaPicker file handling, and scrolling inside shadowed containers.

**Source link**

- [Daily repository status — 12 August 2026](https://github.com/dotnet/maui/issues/37328)
- [Daily repository status — 10 August 2026](https://github.com/dotnet/maui/issues/37246)
- [Daily repository status — 9 August 2026](https://github.com/dotnet/maui/issues/37230)

### Windows Map crash and cross-platform correctness fixes

**What changed**

A Windows lifecycle-safe fix addressed a Map crash when leaving a page. Other August fixes covered stale iOS/Mac Catalyst map element IDs, iOS navigation title behavior, Android accessibility semantics, and platform UI correctness.

**Recommended action**

Test Map lifecycle scenarios during page removal/navigation, and include iOS/Mac Catalyst Map updates plus accessibility checks in release validation.

**Source link**

- [Daily repository status — 12 August 2026](https://github.com/dotnet/maui/issues/37328)
- [Daily repository status — 13 August 2026](https://github.com/dotnet/maui/issues/37374)

### Binding diagnostics memory retention fix

**What changed**

A MAUI fix changed `BindingDiagnostics.BindingFailed` to use weak-event handling, addressing a retention issue where the static event could keep subscribers alive.

**Recommended action**

If your app enables binding diagnostics or has long-lived pages and view models, retest navigation-heavy flows and memory profiles after upgrading to a servicing build containing the fix.

**Source link**

- [Daily repository status — 21 August 2026](https://github.com/dotnet/maui/issues/37701)

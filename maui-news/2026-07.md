## .NET MAUI 10.0.90 stable servicing

**What changed**

- Released July 22 with 231 commits focused on quality, performance, and developer experience.
- The release includes fixes across controls, Shell/navigation, layouts, accessibility, platform handlers, and lifecycle behavior.
- It supersedes June's 10.0.80 servicing baseline.

**Recommended action**

- Move a staging branch to 10.0.90 and test navigation stacks, modal flows, lists, input controls, accessibility, WebView/HybridWebView, and app lifecycle.
- Rebuild Android AAB/APK, Apple archives, Mac Catalyst packages, and Windows MSIX artifacts.
- Keep the previous workload set available until device and store-package smoke tests pass.

**Source link**

- [.NET MAUI 10.0.90 release notes](https://github.com/dotnet/maui/releases/tag/10.0.90)

## .NET 11 Preview 6: CoreCLR is now mandatory on mobile

**What changed**

- For `net11.0-android`, `net11.0-ios`, and `net11.0-maccatalyst`, CoreCLR is now the only runtime; the Mono-selection property was removed.
- Microsoft reports iOS and Mac Catalyst are generally faster than Mono. Android startup and app size are currently within about 10% of Mono.
- On-device `dotnet-trace` and `dotnet-counters` are available with CoreCLR.
- Debugging and Hot Reload work across Visual Studio, VS Code, and `dotnet watch`, but XAML Hot Reload and some iOS paths still have preview limitations.
- Android NativeAOT work now includes a trimmable Android interop type map.

**Recommended action**

- Test a production-shaped app on Preview 6; there is no Mono fallback for .NET 11 mobile targets.
- Record cold/warm startup, package size, working set, GC behavior, crash symbolication, background/resume behavior, P/Invoke, bindings, and reflection-heavy paths.
- Exercise trimming and AOT builds with the same linker descriptors and feature switches used for release.
- Validate debugger, Hot Reload, and diagnostic collection before changing team-wide development images.

## CommunityToolkit.Maui 15.0.0 and .NET 11 compatibility

**What changed**

- CommunityToolkit.Maui 15.0.0 removes its use of internal .NET MAUI APIs.
- Toolkit 14.2.2 and earlier are not compatible with .NET 11.
- The change is specifically intended to keep Toolkit-based applications working when MAUI internals are no longer accessible in .NET 11.

**Recommended action**

- Upgrade Toolkit-based apps to 15.0.0 or later before adopting .NET 11.
- Regression-test Popup, behaviors, converters, DrawingView, and any custom code that depended on Toolkit implementation details.
- Keep the Toolkit and MAUI workload upgrades in the same compatibility test matrix.

**Source link**

- [CommunityToolkit.Maui releases](https://github.com/CommunityToolkit/Maui/releases)

## Visual Studio 2026 July update

**What changed**

- Visual Studio 2026 18.8.0 shipped July 14, followed by 18.8.1 on July 22.
- The release is the supported Windows IDE line for current .NET development; .NET 11 preview work still requires matching preview-capable SDK and workload components.

**Recommended action**

- Update one MAUI development and CI image first, then verify workload installation, Android SDK/emulators, Hot Reload, device deployment, Apple remote-build workflows, and Windows packaging.
- Keep IDE, SDK, workload-set, Android tooling, and Xcode versions recorded together in build diagnostics.

**Source link**

- [Visual Studio 2026 release notes](https://learn.microsoft.com/visualstudio/releases/2026/release-notes)
